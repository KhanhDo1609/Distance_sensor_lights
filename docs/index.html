ARDUINO UNO · HC-SR04 · FIVE FADING LEDs

Closer object. Brighter light.

A proximity-controlled ambient light with a 50 cm range. The bottom LED brightens first, then each LED above it fades in. All five reach full brightness at 2 cm.
